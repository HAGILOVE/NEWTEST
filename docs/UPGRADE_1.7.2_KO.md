# Aether EM 1.7.2 — 선택·치수·곡면 표시 및 HFSS 진단

새 폴더에 압축을 풀고 SETUP_WINDOWS.cmd 실행 후 START_WINDOWS.cmd로 시작해야 함. 기존 HFSS 원본은 보관하고 가져온 프로젝트는 다른 이름으로 저장해야 함.

## 변경 내용

- 원통의 기본 표시 분할을 128개로 늘리고, 같은 면 안에서 정점 법선을 평균하여 곡면 음영을 부드럽게 처리함. 상·하면 및 상자 모서리 경계는 유지함. OCC 표시 메시의 곡률 분할도 강화함. 이는 표시 개선이며 해석 정확도를 높였다는 의미는 아님.
- 화면 왼쪽 버튼 더블클릭으로 도형 선택. Ctrl+D 또는 Fit 버튼으로 전체 보기. 작은 마우스 흔들림은 회전으로 취급하지 않음.
- O: Object, F: Face, E: Edge, V: Point. 마우스를 가까이 가져가면 선택 후보를 강조함. 숨긴 물체와 다른 표면 뒤에 가려진 점은 선택 후보에서 제외함.
- 두 점 측정 버튼을 누르고 두 위치를 순서대로 클릭하면 좌표 사이의 거리와 치수선을 표시함. 12 픽셀 이내의 표시 정점에 스냅함. 같은 점 중복 선택은 거부함. Esc로 취소. V 모드에서도 Ctrl+두 번째 점 클릭으로 측정 가능함.
- DXF 열린 참조선에도 점·선 선택 정보를 제공함. 닫히지 않은 선은 면/체적을 가진 해석 형상이 아님.
- 측정 중 초안선 표시의 undefined proj/view 오류와 완료 직후 더블클릭 충돌을 수정함. 늦게 도착한 일반 선택 치수 응답이 두 점 측정을 덮어쓰지 않도록 처리함.
- HFSS 재료 항목이 비어 있으면 다른 재료 이름 항목도 확인함. 확인할 수 없는 재료는 표시용 vacuum 대체임을 명시하고, 올바른 재료를 지정하기 전에는 해석을 차단함.
- Edit > HFSS Import Status에서 누락 형상·미확인 재료·미지원 가져오기 항목과 CSV 보고서를 확인할 수 있음. 관련 오류 상태는 저장/다시 열기에도 유지됨.
- 1.7.1의 STEP 조립체 이름 오류, DXF 선/호 연결, UTF-16 HFSS 및 압축 프로젝트 경로 수정 포함.

## 첨부 HFSS 오류의 의미와 남은 제한

62개 중 58개가 읽을 수 없는 native Parasolid 형상이라는 로그는 가져오기가 완전하지 않다는 뜻임. 이번 버전이 Parasolid 변환기를 새로 구현한 것은 아님. 해당 형상은 HFSS에서 STEP으로 내보낸 후 Modeler > Replace CAD Source로 교체해야 함. 미지원 경계/포트 및 재료도 진단 보고서에 따라 복원해야 하며, PML 등 기존 엔진이 지원하지 않는 기능은 이 버전에서도 지원하지 않음. 가져오기 경고만 숨기고 해석을 진행하는 방식으로 해결하지 않았음.

점 측정은 표시 정점 좌표를 사용함. 곡선의 점·선은 테셀레이션 샘플이므로 정확한 BREP 정점·곡선 길이와 다를 수 있음. 정밀 작업은 좌표와 기존 수치 입력/기본 형상 치수 기능을 함께 확인해야 함. 큰 CAD에서는 CPU 선택 계산이 느릴 수 있음.

## 검증

pytest: 458개 중 340개 통과, 118개 건너뜀, 오류/실패 0개. XML: test-results-1.7.2.xml. Python 컴파일 및 두 JavaScript 파일 구문 검사 통과. tests/test_release_172.py에는 곡면/끝면 법선, 실루엣 오차, DXF 참조 선택 정보, 미확인 가져오기 정보의 저장과 재료 수정, Node 기반 이벤트/스냅 검사를 추가함. Node 검사는 가짜 GPU 버퍼를 사용하는 로직 검사이며 실제 브라우저 렌더 검사가 아님.

현재 환경에서 CAD 커널은 libGLU 부족으로 실행되지 않고 실제 브라우저/Windows 검증도 완료하지 못함. 사용자 원본 HFSS·STEP·DXF는 제공되지 않아 첨부 모델 자체의 재현 검증은 불가했음. 이전 docs/screenshots는 이전 버전 자료이며 1.7.2의 실행 증거가 아님.

## Windows 확인 순서

1. 원통을 만들고 회전·확대하여 측면 음영과 끝면 경계 확인.
2. 두 도형을 더블클릭하여 각각 선택하고 Ctrl+D로 전체 보기 확인.
3. O/F/E/V 각각 호버 강조 및 클릭 선택 확인. DXF 참조선은 E/V로 확인.
4. 두 점 측정 버튼 → 서로 다른 두 정점 클릭 → 좌표/단위/치수선 확인. Esc 취소와 CSV 내보내기도 확인.
5. HFSS 열기 → Import Status 확인 → 형상 교체 및 재료 수정 → 다른 이름으로 저장 → 다시 열어 형상과 오류 상태 확인.
6. 수정 전에는 누락 형상/미확인 재료가 해석을 막는지 확인. STEP 조립체 및 DXF 원본 재현에 문제가 남으면 원본 파일과 전체 로그가 필요함.
