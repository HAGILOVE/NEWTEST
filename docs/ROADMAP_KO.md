# Warps 대비 기능 현황과 우선순위

판단 기준: **전자파 해석 결과가 틀리거나 아예 못 푸는 것**을 먼저, 편의 기능은 그 다음. 구현 난이도와 검증 가능성(해석해가 있는가)도 고려함.

## 현황

| 영역 | 기능 | 상태 |
|---|---|---|
| 솔버 | Driven Modal(1·2차, 적응형 메시) | 있음 |
| | Interpolating / Fast 스윕 | **1.8.0에서 구현**(이전엔 라벨뿐) |
| | Eigenmode(Q 포함) | **1.8.0에서 구현**(Radiation 경계 제외) |
| | Driven Terminal(차동/다중도체) | **없음** |
| | PML, 주기 경계(Master/Slave), Floquet 포트 | **없음** |
| | Incident wave(평면파), RCS | 없음 |
| | 열/기계 연동, SAR | 없음 |
| 포트·경계 | Wave / Lumped Port, 적분선, de-embed, 재정규화 | 있음 |
| | PEC/PMC/임피던스/유한 도전율/Radiation/Lumped RLC/대칭 | 있음 |
| 후처리 | S/Z/Y, Smith, VSWR, 군지연 | 있음(Smith·Z는 1.8.0) |
| | E/H/Js 필드·컷 플레인·위상 애니메이션 | **1.8.0** |
| | 원거리장·이득·효율·축비 | **1.8.0** |
| | Output variables, 필드 계산기, 적분 | 없음 |
| 최적화 | 변수 범위+목표 최적화 | **1.8.0**(Sensitivity/Tuning 없음) |
| 모델러 | 프리미티브, 불리언, 변환, 수식 치수, 마우스+Tab 드로잉 | 있음(1.8.0 보강) |
| | 폴리라인/스플라인, 스윕/로프트 히스토리 | 없음 |
| | 상대 좌표계 | 없음 |
| 파일 | .warp 읽기/쓰기, Touchstone, STEP/IGES/DXF | 있음 |
| | ACIS(.sat/.sab), Parasolid 직접 읽기 | 불가(비공개 포맷, STEP 경유) |

## 다음 우선순위

1. **Driven Terminal** — 마이크로스트립·차동 쌍 등 다중 도체 포트의 S-파라미터에 필요. Lumped Port 묶음에 차동/공통 모드 변환(`SParameters.to_mixed_mode`는 이미 있음)을 연결하면 1차 지원 가능. 해석해: 결합 선로의 짝/홀 모드 임피던스.
2. **PML** — Radiation 1차 흡수 경계의 반사(영역 크기 의존)를 없앰. 좌표 늘림(stretched coordinate)이 비등방 재료 텐서를 요구하므로 요소 조립을 스칼라 ε/μ에서 텐서로 확장해야 함. 가장 큰 구조 변경.
3. **주기 경계 + Floquet 포트** — 배열 안테나/주파수 선택 표면. 마스터/슬레이브 면의 메시 일치(gmsh `setPeriodic`)와 위상 구속이 필요.
4. **출력 변수·필드 계산기** — 임의 S 조합/필드 적분(예: 면적분 전력, 라인 적분 전압)을 리포트에 사용.
5. **폴리라인/스윕 모델링**, 상대 좌표계 — 코일·미앤더 형상 입력 편의.
6. **Sensitivity / Tuning** — 최적화 결과 주변의 민감도, 슬라이더로 변수를 바꿔 보기.
7. **Eigenmode + Radiation 경계** — 비선형 고유치 문제의 안정적 풀이(현재는 거부). PML 이후에 의미가 큼.

## 알려진 정확도 한계

- Radiation은 1차 흡수 경계라 방사체에서 λ/4 이상 떨어뜨리고 2차 요소를 권장. 이득·효율은 *영역 점검*(경계 전력/원거리장 전력)이 1 근처일 때만 신뢰.
- 포트 2D 모드 해석이 조밀 QZ라 포트 면 자유도가 큰 모델에서 주파수당 비용이 큼(대형 포트는 shift-invert로 전환).
