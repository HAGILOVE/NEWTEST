# Aether EM 1.7.3 — 월드 축, 외곽선 선택, 치수 보관, solum.aedt 진단

새 폴더에 압축을 풀고 SETUP_WINDOWS.cmd → START_WINDOWS.cmd 순서로 실행해야 함. 기존 원본 프로젝트는 별도로 보관해야 함.

## 사용 방법과 수정 내용

| 요구 기능 | 변경 및 사용 방법 |
|---|---|
| Move 시 절대 축 유지 | 격자는 월드 XY 평면 Z=0, 원점 (0,0,0) 기준으로 고정됨. 첫 모델에서 정한 격자 간격은 도형 이동 시 유지됨. 월드 X/Y/Z 축선 추가. 카메라 Pan/Rotate는 월드 축을 보는 시점을 바꾸는 동작임. |
| 좌하단 방향축 | 화면 모서리에 고정된 화살표와 X/Y/Z 글자 표시. 도형 이동·카메라 Pan에 따라 위치가 변하지 않고, 카메라 회전에 따라 방향만 변함. |
| 전체 Edge 선택 | E 모드에서 같은 면의 연결된 외곽선 전체를 강조·선택함. 사각 면은 둘레 전체, 원통 끝면은 원주 전체 선택. 구멍 등 서로 떨어진 루프는 별도로 선택됨. 이것은 개별 BREP edge가 아니라 연결된 face-outline 선택임. |
| 외곽선 길이·거리 | 전체 외곽선의 선분 길이를 합산하고, 두 외곽선 거리는 양쪽 모든 선분에서 최소거리를 구함. 곡선 길이는 테셀레이션 근삿값임. |
| Select Point | 우클릭 → Select Point. 첫 정점 클릭 후 다른 정점을 클릭하면 두 점 측정. Ctrl은 필요 없음. 우클릭 → Measure Point to Point도 가능. |
| 좌표와 거리 | 결과에 P1/P2의 X/Y/Z, ΔX/ΔY/ΔZ 및 거리를 함께 표시함. 표시 정점에 스냅하며 곡선 위 점은 분할 샘플임. |
| 치수 계속 표시 | 결과창의 Keep on screen 또는 우클릭 Keep Measurement 사용. 여러 측정값을 화면 우측 카드에 보관함. 일반 선택 변경·도형 이동 후에도 카드 유지. |
| 치수 숨기기 | 우클릭 Show / Hide Measurements 또는 툴바 버튼. 현재 치수선·숫자와 보관 카드 표시를 전환함. 카드 × 또는 Clear Kept Measurements로 삭제. |

보관 치수는 측정 시점의 좌표와 값에 대한 스냅샷임. 도형 편집 후 자동 재계산되는 연관 치수가 아니며, 프로젝트 파일에 저장되는 영구 주석도 아님. 프로젝트 열기/새로 만들기/디자인 전환 시 보관 카드 초기화. 필요한 기록은 CSV로 내보내야 함. 큰 CAD의 외곽선 선택과 두 외곽선 최소거리 계산은 선분 수에 따라 느려질 수 있음.

## solum.aedt에서 실제 확인한 문제

사용자가 첨부한 원본으로 Python 가져오기를 재현함. 사용자 원본 자체는 배포 ZIP에 포함하지 않음.

| 디자인 | 1.7.2에서 읽힌 솔리드 수 | 1.7.3에서 읽힌 솔리드 수 | 1.7.3 미해결 가져오기 항목 |
|---|---:|---:|---:|
| HFSSDesign1 | 1 | 16 | 28 |
| HFSSDesign2 | 1 | 16 | 22 |

각 디자인에서 15개의 단일 Sweep 직육면체를 추가 복원함. 6개 직사각형 면, 8개 꼭짓점, 면적 및 모서리 좌표의 일치를 검사하고, 이후 편집 연산이 없는 경우에만 복원함. 임의 형상을 경계상자로 대체하지 않음. HFSS 색상과 투명도도 읽음.

기존에 보였던 Box1에는 MoveFaces 등이, Cylinder3에는 Substract/Unite 등이 포함됨. 이전 코드가 최초 생성 도형을 읽었다는 사실만으로 최종 HFSS 형상을 복원했다고 볼 수 없음. 이제 이력 불완전을 오류 보고서에 명시하고 해석을 차단함. 전체 보고서는 solum-validation-1.7.3.json 참조.

**이 버전도 전체 HFSS/PML 호환이 아님.** Region 및 복잡한 Sweep/Boolean/Split/MoveFaces 이력, 커널 face ID 경계 연결, native Parasolid, PML constitutive model은 해결되지 않았음. 복원된 PML 형상의 외형이 보이는 것과 PML 전자기 해석이 동작하는 것은 별개임. 미확인 재료와 미해결 경계/형상 오류는 계속 보고함.

불완전하게 읽힌 기본 도형도 Modeler → Replace CAD Source에서 월드 좌표 기준 단일 솔리드 STEP으로 교체할 수 있게 수정함. 검증된 파일을 적용한 뒤 해당 객체의 불완전 이력 오류만 제거함. 다른 재료·경계 오류는 유지함. Undo하면 형상과 오류 상태도 복원됨. 아예 생성되지 않은 객체는 STEP 가져오기 후 원래 이름과 경계 조건을 복구해야 함. PML을 그대로 실행할 수는 없으므로 실제 해석 모델은 지원되는 경계 조건으로 별도 재구성·검증해야 함.

## 검증 범위

- 전체 pytest 464개: 346개 통과, 118개 건너뜀, 실패/오류 0개. test-results-1.7.3.xml 포함.
- 새 테스트: 고정 격자, 화면 고정 방향축 X/Y/Z, 연결 외곽선, 실제 원통 표시 버퍼의 전체 원주, 전체 외곽선 거리, 검증된 직육면체 복원 및 잘못된/과거 토폴로지 거부, STEP 교체/Undo.
- 기존 프로젝트 재저장 동일성 테스트에서 발견한 색상 회귀도 수정 후 통과.
- Python 컴파일, JavaScript 구문 검사 통과.
- 사용자 solum.aedt 파싱·복원은 실제 파일로 실행했음. 실제 Windows/browser 렌더 및 OCC STEP 실행은 환경 제한으로 검증하지 못함. Node 테스트는 GPU/DOM 일부를 대체하는 로직 검사임. 346개 통과가 모든 GUI 기능의 실사용 검증을 의미하지는 않음.

## Windows 확인 순서

1. Box 또는 Cylinder를 생성하고 Move로 XYZ 각각 이동. 격자 원점/높이가 따라가지 않는지 확인.
2. Pan/Rotate/Zoom하며 좌하단 화살표·문자 확인.
3. E로 사각 면과 원통 끝면 선택. 선택 외곽선과 둘레 수치 확인.
4. 우클릭 Select Point → 두 점 클릭 → 좌표, 델타, 거리 확인.
5. Keep on screen → 선택 변경 → Show / Hide → 개별 삭제 확인.
6. solum.aedt 열기 → 디자인별 Import Status 확인. 원본 HFSS에서 내보낸 STEP으로 불완전 객체 교체 후 다시 저장/열기 검증.
